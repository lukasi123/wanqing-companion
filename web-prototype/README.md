# 眉间 · 深海工坊界面重做版

## 打开网页

双击 `index.html`。所有前端代码均在 HTML 内，没有构建步骤。

本版按 DSH 皮肤中心热门列表首位 **Abyssal Maid Atelier / 深海女仆工坊** 的公开画面改版：深蓝宫殿、双侧人物、金色细边、蕾丝输入区。移除了旧版的大幅文案、印章头像和固定右侧说明栏。角色资料改为右上角点击展开。外观按钮可以切换同一原版的深浅画面。

**图片在线加载：** 主题人物和背景来自上游公开 WebP 预览图的无文字区域裁切，需要浏览器能访问 raw.githubusercontent.com。本包未包含已下载的原图。图片加载失败时，聊天功能继续工作；右上角“深海工坊”可重试。

## 保存为完全离线版

在可以联网的电脑中，于本目录运行：

```sh
python download_artwork.py
```

程序只下载两张已标明来源的图片，并将图片嵌入网页，生成 `眉间_深海工坊_离线完整版.html`。无额外 Python 依赖。联网版始终保留，不会被覆盖。也可将原图分别放到 `assets/maid-atelier-dark.webp` 和 `assets/maid-atelier-light.webp` 后再运行。

## 已保留的功能

聊天、发送与停止、历史会话、片段保存；共同记事的增删改与筛选；八套角色选择；称呼与聊天偏好；两套演示档案；导出记录；额度与临时聊天；深浅主题；手机导航。

原版浏览器记录键 `meijian-campus-v1` 保留。同一站点/浏览器下使用时沿用原记录。不同本地文件路径的浏览器存储归属由浏览器决定，重要记录可先从旧版导出。

独立打开时为示例回复，没有声称已连接学校模型。

## 接模型

沿用上一版 `server.py` 和 `roles.json`。Python 3.10+，仅本机服务。

PowerShell 示例：

```powershell
$env:MODEL_BASE_URL = "https://学校或授权服务地址/v1"
$env:MODEL_NAME = "实际模型名称"
$env:MODEL_API_KEY = "实际应用密钥"
python server.py
```

然后在浏览器打开 `http://127.0.0.1:8765`。`.env.example` 只作变量说明，不自动加载。

## 画面与来源

本版复用的是上游效果图中人物和场景的裁切，不是把整张网站截图当成可操作界面；聊天、按钮、记事和设置仍是真实 HTML 元素。未下载或集成上游 DSH 插件运行包，未宣称与该插件实时联动。人物图是主题原角色，不是郑大原创角色定稿。

源码适配和原来的产品功能仍在 `index.html`；原主题署名、许可和修改说明见 `SOURCE_NOTICES.md`。不包含字体文件。
